1. IFrame Examples

An iframe embeds another HTML document inside the current page.

Iframe Attributes

AttributePurpose
srcSpecifies the embedded page URL.
titleProvides an accessible description.
width and heightSet the display dimensions.
loading="lazy"Loads the iframe when it is near the viewport.
sandboxRestricts potentially unsafe iframe capabilities.

Responsive IFrame Structure

<div>
    <iframe title="Responsive video" src="https://example.com" loading="lazy"></iframe>
</div>

The surrounding container can be sized by the page layout so the embedded content remains usable on different screens.

2. HTML Head and Metadata

The <head> section stores information about a webpage rather than visible page content.

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="HTML learning page">
    <title>HTML Learning Page</title>
</head>
Charset
Defines the character encoding used by the document.
Viewport
Helps the page scale correctly on mobile devices.
Description
Summarizes the page for search engines and previews.

4. URI Encoding

5. Legacy HTML Frames

The old <frameset> and <frame> elements divided a browser window into sections. They are obsolete in HTML5, so modern pages should use regular layout elements and iframes instead.

<!-- Historical example; do not use in new HTML5 pages -->
<frameset cols="50%,50%">
    <frame src="left.html">
    <frame src="right.html">
</frameset>
