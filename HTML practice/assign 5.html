2. CSS Backgrounds

Multiple background layers

This example combines a solid color, radial gradient and linear gradient.

body {
    background-color: lightblue;
    background-image: url("background.jpg");
    background-repeat: no-repeat;
    background-position: center top;
    background-size: cover;
    background-attachment: fixed;
}

div {
    background-image: url("layer1.png"), url("layer2.png");
    background-position: center, top right;
}

3. CSS Box Model

Every element is a box made of content, padding, border and margin.

LayerDescriptionCSS property
ContentText or image inside the elementwidth, height
PaddingSpace between content and borderpadding
BorderSurrounds content and paddingborder
MarginSpace outside the bordermargin
Content area
Padding: 20px
Border: 5px
Margin: 15px
div {
    width: 200px;
    height: 100px;
    padding: 10px;
    border: 5px solid black;
    margin: 15px;
    box-sizing: border-box;
}

With the default content-box model, total width includes content, padding and border. With border-box, the declared width includes padding and border.
