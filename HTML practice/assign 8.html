Understanding box-sizing

Both cards use the same declared width, padding, and border. Their sizing models determine how much space they occupy.

Compare the two sizing models

Example 01

content-box

The default model. Width applies only to the content, so padding and borders are added to the final size.

Declared width: 300px Content width: 300px Padding + border are added
CSS rule
box-sizing: content-box;
Rendered width
348px
Example 02

border-box

The predictable model. The declared width includes both the padding and border, keeping the total size at exactly 300px.

Declared width: 300px Content width: 252px Padding + border fit inside
CSS rule
box-sizing: border-box;
Rendered width
300px

Key takeaway: border-box makes width calculations easier to predict.
