Absolute and Relative Units

18px: pixels
1cm: centimeters
1in = 2.54cm: inches
1.3em: parent font size
1.5rem: root font size
80%: parent width
20vw: viewport width
10vh: viewport height
vmin and vmax: viewport dimensions
